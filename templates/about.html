How FraudGuard works

1. Prepare data

The transaction dataset is separated into 30 input features and the Class target.

2. Scale features

StandardScaler puts numeric features on comparable scales before training.

3. Balance classes

SMOTE creates synthetic examples for the minority fraud class during training.

4. Predict

Logistic Regression estimates the probability that a transaction belongs to the fraud class.
